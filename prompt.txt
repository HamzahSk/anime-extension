# Task: Create MovieBox Extension (`src/all/moviebox`)

Buat ekstensi baru untuk:

```text
https://themoviebox.xyz/
```

Belum ada implementasi sebelumnya, jadi lakukan analisis dan scraping dari nol.

Gunakan ekstensi movie lain di repository sebagai referensi arsitektur, coding style, HTTP client, helper, filter, dan video extractor. Jangan menyalin scraper, sesuaikan dengan struktur website MovieBox saat ini.

## Requirements

- Analisis website secara menyeluruh menggunakan DevTools/Network.
- Gunakan endpoint API/AJAX jika tersedia, jangan hanya scraping HTML.
- Implementasikan:
  - Home
  - Search + Pagination
  - Movie/TV Detail
  - Episode (jika ada)
  - Streaming
- Tambahkan filter (Genre, Country, Year, Quality, dll.) jika website mendukungnya.
- Pastikan seluruh server video berhasil diekstrak dan dapat diputar (m3u8/mp4/embed sesuai kebutuhan).
- Gunakan helper, extractor, dan utilitas yang sudah tersedia di repository sebisa mungkin.
- Tangani headers, referer, cookies, interceptor, atau proteksi lain jika diperlukan.

## Validation

Pastikan:

- Scraping berhasil mengambil data terbaru.
- Search, filter, dan pagination berfungsi.
- Detail dan episode berhasil diparsing.
- Streaming benar-benar bisa diputar tanpa error.

Lalu jalankan:

```bash
./gradlew spotlessApply
./gradlew spotlessCheck
./gradlew testDebugUnitTest
```

Perbaiki seluruh error hingga build dan test selesai tanpa kegagalan.
