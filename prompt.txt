Task: Repair Xvideos Extension (src/all/xvideos)

Analisis dan perbaiki extension pada:

src/all/xvideos

Gunakan extension lain di repository yang sudah berhasil melakukan ekstraksi HLS (.m3u8) sebagai referensi implementasi. Tetap ikuti arsitektur repository, coding style, serta penggunaan AnimeHttpSource, OkHttpClient, headers, cookies, interceptor, dan HLS/video extractor yang sudah tersedia.

Problem

Saat ini extractor hanya mengembalikan master playlist:

https://hls-cdn77.xvideos-cdn.com/.../hls.m3u8

Padahal file tersebut hanyalah variant playlist yang berisi daftar kualitas video, misalnya:

#EXTM3U

#EXT-X-STREAM-INF:PROGRAM-ID=1,BANDWIDTH=763904,RESOLUTION=854x480,NAME="480p"
hls-480p-9d4e7.m3u8

#EXT-X-STREAM-INF:PROGRAM-ID=1,BANDWIDTH=2760704,RESOLUTION=1920x1080,NAME="1080p"
hls-1080p-f5327.m3u8

#EXT-X-STREAM-INF:PROGRAM-ID=1,BANDWIDTH=444416,RESOLUTION=640x360,NAME="360p"
hls-360p-a9585.m3u8

Sedangkan setiap file hasil di atas (hls-480p-*.m3u8, hls-1080p-*.m3u8, dll) merupakan media playlist yang berisi segmen .ts, contohnya:

#EXTM3U
#EXTINF:10,
hls-480p-58d1c0.ts
#EXTINF:10,
hls-480p-58d1c1.ts
...
#EXT-X-ENDLIST

Media playlist tidak perlu diparse lagi menjadi daftar .ts. Player HLS akan menangani segmen tersebut secara otomatis.

Required Fix

Perbaiki extractor agar:

1. Request ke URL master playlist (hls.m3u8).


2. Parse seluruh pasangan:

#EXT-X-STREAM-INF

URL playlist yang berada tepat pada baris berikutnya.



3. Ambil label kualitas secara dinamis:

Prioritaskan atribut NAME.

Jika tidak ada, gunakan RESOLUTION.

Jika keduanya tidak ada, gunakan BANDWIDTH.



4. Resolve URL relatif menjadi URL absolut menggunakan URL master playlist.



Contoh:

Master:

https://hls-cdn77.xvideos-cdn.com/.../hls.m3u8

Entry:

hls-480p-9d4e7.m3u8

Hasil:

https://hls-cdn77.xvideos-cdn.com/.../hls-480p-9d4e7.m3u8

5. Buat satu objek Video untuk setiap variant/media playlist, misalnya:



360p

480p

720p

1080p


6. URL pada setiap Video harus berupa media playlist (*.m3u8), bukan master playlist dan bukan daftar .ts.


7. Pastikan seluruh kualitas dapat diputar langsung oleh aplikasi menggunakan extractor/player HLS yang sudah digunakan extension lain di repository.



Requirements

Jangan mengubah public API extension kecuali benar-benar diperlukan.

Pertahankan coding style repository.

Gunakan utilitas/extractor HLS yang sudah ada bila memungkinkan.

Jangan hardcode daftar kualitas.

Parsing harus sepenuhnya dinamis sehingga tetap bekerja jika server menambah atau mengurangi kualitas (240p, 360p, 480p, 720p, 1080p, 1440p, dst).

Tangani URL relatif maupun absolut.

Abaikan komentar atau directive HLS yang tidak relevan.


Expected Result

Jika master playlist berisi:

360p -> hls-360p.m3u8
480p -> hls-480p.m3u8
720p -> hls-720p.m3u8
1080p -> hls-1080p.m3u8

Maka extractor harus mengembalikan empat objek Video, masing-masing menunjuk ke:

.../hls-360p.m3u8

.../hls-480p.m3u8

.../hls-720p.m3u8

.../hls-1080p.m3u8


bukan satu Video yang masih menunjuk ke hls.m3u8.

Validation

Pastikan seluruh perubahan lolos:

./gradlew spotlessApply
./gradlew spotlessCheck
./gradlew testDebugUnitTest

Perbaiki seluruh error maupun warning hingga seluruh proses selesai tanpa kegagalan.
